    4. Verificación de seguridad

    Este campo aplica un tratamiento especial: la empresa solo lo solicita porque parte del catálogo corresponde a equipo restringido, cuya entrega exige verificar que quien lo recibe está autorizado para manipularlo. No se solicita para ningún otro fin.
    Sensible
    Requerido únicamente para pedidos que incluyan equipo táctico restringido (categoría "Equipo táctico" del catálogo).

    Aviso legal — dato de tratamiento especial (Art. 6, Ley 1581 de 2012 y Decreto 1377 de 2013):

    • Finalidad exclusiva: verificar que el funcionario que recibe equipo restringido está autorizado para manipularlo.
    • Carácter: no es obligatorio para registrarte ni para comprar productos de dotación u oficina.
    • Consecuencia de no autorizar: si el pedido incluye equipo restringido y no autorizas este dato, no podremos procesar la entrega de esos artículos específicos; el resto del pedido no se ve afectado.
    • Acceso: visible únicamente para el área de cumplimiento y seguridad.

    Privacidad · Ley 1581 de 2012

    ¿Por qué clasificamos cada dato?

    La Ley 1581 de 2012 exige un tratamiento diferenciado según el nivel de sensibilidad de la información. Marcar cada campo con su clasificación permite auditar qué se recolecta, por qué, y aplicar el nivel de acceso y cifrado correcto en el backend para cada categoría.

    Los datos privados se almacenan cifrados en reposo. Los semiprivados son visibles también para contabilidad. Los públicos no requieren restricción. Los sensibles (antecedentes judiciales) se guardan en una tabla aparte, cifrada, visible solo para cumplimiento y seguridad.

    Política de tratamiento de datos

    Suministros Institucionales S.A.S. actúa como responsable del tratamiento de los datos personales recolectados en este formulario, conforme a la Ley 1581 de 2012 y el Decreto 1377 de 2013.

    Finalidad: gestión de pedidos, facturación, logística de entrega y atención al cliente.

    Datos de tratamiento especial: únicamente para pedidos de equipo táctico restringido, se solicita el número de consulta de antecedentes judiciales del funcionario receptor, bajo consentimiento separado, expreso y voluntario.
